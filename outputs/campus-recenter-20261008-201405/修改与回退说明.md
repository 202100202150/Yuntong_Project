# 场景块居中与放大

本次只修改 `desktop-app/lib/campus-buildings.ts`：

- 删除所有建筑名称、楼号标签及其底色牌的绘制；摄像机 C1/C2、坐标轴和检测信息保留。
- 以六组建筑全部体块的 X/Z 外轮廓范围中心作为整组中心，并将该中心移动到原点。
- 建筑位置、宽度、深度和高度统一乘以 1.17，保持相对布局、体块形状和楼高比例。
- 所有建筑底部仍位于 Y=0。最终范围为 X `[-5.4873, 5.4873]`、Z `[-4.068675, 4.068675]`，未超出 X/Z `[-6,6]` 的地面。

本次没有修改场景投影、默认视角、旋转、平移、缩放、检测逻辑或摄像机配置。预览截图通过原有旋转操作选择能查看六组建筑的视角，检测点为验证数据。

本目录 `campus-buildings.before.ts` 保存修改前的名称、位置及尺寸。关闭应用后运行 `restore-before-recenter.ps1` 即可撤销本次修改，然后按原来的方式重新启动项目。
