# 2D / 3D 场景切换

在标题右侧增加左 3D、右 2D 的按钮。初始仍为原来的 3D 场景。

切换到 2D 后标题为“2D 平面定位”，采用从 +Y 看向 -Y 的俯视图：X 向右、Z 向下，仅显示地面网格、X/Z 坐标轴和原点，隐藏 Y 轴、Y 刻度与竖直参考面。建筑俯视轮廓直接来自同一组三维体块；同高度共边合并，庭院与不同高度屋顶的分界保留。2D 可拖动平移、滚轮缩放。

每次切换到另一模式，都恢复该模式的初始视角、缩放与平移。3D 的初始视角、旋转和平移行为保持原样。重置视角按钮恢复当前模式。

模式切换仅使用场景组件内部状态，两种模式共用父组件传入的检测对象和匹配信息。切换不调用摄像机或检测启停接口，不重挂载检测工作区；2D 显示 X/Z 坐标，返回 3D 后继续显示目标及原有 X/Y/Z 坐标。

修改范围：desktop-app/components/spatial-scene.tsx、desktop-app/components/spatial-scene.css、desktop-app/lib/campus-buildings.ts。本目录按原路径保存这三个文件的修改前版本。关闭应用后运行 restore-before-2d-3d.ps1，即可撤销本次切换功能并恢复本次修改前的场景，随后按原启动方式重启项目。

浏览器预览采用模拟检测数据验证显示，不表示本次进行了实际摄像机连接测试。验证结果另见本目录 change-record.json 和项目 work/scene-2d-3d-20261009-113818 下的检查记录。
