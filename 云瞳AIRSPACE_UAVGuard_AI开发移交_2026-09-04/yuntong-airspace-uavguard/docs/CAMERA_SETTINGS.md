# DS-2CD3T86WDA-PW 建议设置

在安装前导出每台相机的原始配置和固件版本。以下参数是试点基线，调整后
必须记录到标定版本中。

## 视频

- 主码流：3840×2160，25 fps，H.265，CBR 8 Mbps，I帧间隔/GOP 25；
- 关闭Smart265、SVC、慢快门和电子防抖；
- 关闭或降低强3D降噪，避免小目标被时间降噪抹除；
- 白天固定或限制快门到约1/1000秒，限制增益，确保目标拖影不超过约1像素；
- 固定白平衡与焦点；安装完成后不再改变镜头、变焦、分辨率或电子裁剪；
- ROI增强可以覆盖共同天空区域，但不能改变输出几何尺寸。

## 网络与安全

- 相机地址放入独立VLAN，例如`192.168.50.0/24`，只允许计算节点访问；
- 建立只读取流账户，不使用管理员账户作为RTSP账户；
- 修改默认密码、禁用UPnP/萤石云/不需要的服务并启用HTTPS；
- 两机和计算节点指向同一台本地NTP服务器；
- 千兆交换机端口启用链路监测，摄像头链路丢包应低于0.5%；
- RTSP路径通常为`/Streaming/Channels/101`，以相机实际固件为准。

## 同步

当前MVP优先使用视频PTS，无法获得绝对RTCP时间时退回到本机到达时间。
安装时必须录制共同可见的高亮闪灯并运行：

```bash
python tools/sync_flash.py --first cam01.mp4 --second cam02.mp4 \
  --first-roi 100,100,60,60 --second-roi 120,90,60,60
```

把输出写入相应相机的`timestamp_offset_ms`。现场验收若同步残差P95超过
20 ms，应改用带RTCP/NTP映射的GStreamer管线或升级为支持PTP/外触发的相机，
不得通过放宽几何门限掩盖同步问题。
