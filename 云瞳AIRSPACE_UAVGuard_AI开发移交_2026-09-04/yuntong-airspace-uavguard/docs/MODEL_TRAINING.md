# 候选区域模型训练

运动和双目几何在没有AI权重时可以独立运行，但所有类别会安全地输出为
`unknown`。分类模型不能用通用COCO权重冒充现场无人机模型。

## 数据设计

- 类别顺序固定为：`multirotor`、`fixed_wing_uav`、`bird`、`unknown`；
- 使用公开Anti-UAV数据进行预训练，最终训练必须加入两台现场相机的原始画面；
- 采集不同距离、方向、云层、逆光、树梢、昆虫、客机和无目标天空；
- 训练/验证/测试按完整飞行批次和日期划分，禁止随机拆分相邻视频帧；
- 单独保留学校现场的盲测批次，不在调参过程中查看；
- 低于8像素的目标只用于运动探测，不强行标注细分类；低于分类门限的输出
  应归入`unknown`。

建议首轮至少包含20个受控飞行批次、12小时负样本视频和5000个经复核目标
实例。固定翼类别必须使用真实模型固定翼飞行数据，不能仅靠合成图。

## YOLOX-tiny导出约定

使用官方YOLOX仓库的Apache-2.0实现进行四类微调，训练时重点使用4K图像的
局部切片与小目标增强。导出ONNX时启用解码输出，使输出形状为
`[1, N, 5 + 4]`，各项为`cx,cy,w,h,objectness,class scores`。运行时适配器也
接受一个输出四类logits的候选裁剪分类包装器。

模型部署前必须记录：

- 训练代码提交、配置、数据集清单和哈希；
- ONNX SHA-256、输入尺寸、类别顺序和验证指标；
- 各距离段召回率、宏平均F1、鸟类误报率以及校准后的置信度阈值。

将最终文件放到`models/uav-roi-classifier.onnx`，安装GPU推理依赖：

```bash
pip install -e '.[inference]'
```

如果模型文件存在而ONNX Runtime不可用，服务会明确启动失败；如果模型文件
不存在，服务继续运行但只输出`unknown`。
