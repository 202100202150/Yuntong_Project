# 云瞳 AIRSPACE 前端

校园低空监测的第一版交互工作台。独立于现有 Python 后端，不替换 `src/uavguard/static/dashboard.html`。

当前视觉主题采用海雾蓝配色：`#3368A0` 主蓝、`#66A3BF` 天空蓝、`#C8DFDB` 雾绿色和 `#F2EFE7` 暖白。蓝色侧栏用于全局导航，暖白卡片承载数据，三维空域使用低饱和蓝绿图层；告警仍保留少量琥珀色语义提示。

## 已实现

- 基于 ENU 坐标的可旋转、缩放、聚焦的正交三维投影视图，2D 俯视切换；键盘与触摸操作。
- 多旋翼、固定翼无人机、鸟类、未知目标四类的 10 Hz 模拟轨迹。
- 实时坐标、速度、标准差、重投影误差、状态与分类置信度；目标搜索、过滤与快照导出。
- 双固定相机和单云台的视频通道布局、MJPEG 播放、放大和异常重连。
- 事件中心、录像链接、本机会话已阅标记、可选本机声音提示。
- 对接现有 REST 与 WebSocket 契约；异常消息校验、乱序保护、失联提示和 5 秒过期移除。
- 明确区分前端模拟、后端模拟与网关数据；真实模式不回退到模拟数据。

## 本地启动

使用 Node.js 22.13+（已在 Node 24 验证）。

```powershell
cd frontend
npm ci
npm run dev
```

打开开发服务打印的地址，默认 `http://localhost:3000/`。默认完全离线模拟，无需启动相机或后端。

### 对接现有 Python 演示后端

在项目根目录的另一个终端启动原有 `uavguard --config config/demo.yaml`，服务地址默认为 `http://127.0.0.1:8080`。然后在网页“接入配置”选择“实时网关”，基础地址留空。

开发代理会把 `/api/*` 和 `/ws/*` 转给该后端。`/api/v1/config` 返回 `demoMode: true` 时，页面会显示“后端模拟”，不是“真实飞行”。修改开发代理目标可在启动前设置环境变量 `UAVGUARD_BACKEND`。

### 实时接口

| 接口                             | 用途                                    |
| -------------------------------- | --------------------------------------- |
| `GET /api/v1/config`             | 相机 ID、后端模拟标志                   |
| `GET /api/v1/health`             | 相机健康、FPS、同步残差、模型状态       |
| `GET /api/v1/tracks/active`      | 初始/补偿快照 `{ "tracks": [...] }`     |
| `GET /api/v1/events?limit=100`   | 历史事件 `{ "events": [...] }`          |
| `WS /ws/tracks`                  | 每条消息为一个 TrackEvent，不是快照数组 |
| `GET /api/v1/cameras/{id}/mjpeg` | 浏览器可播放的 MJPEG 视频               |
| `GET /api/v1/recordings/{path}`  | `metadata.recordingSegments` 指向的录像 |

字段与根项目 `TrackEvent.to_dict()` 保持一致。前端不做三角测量或分类。坐标单位为米，ENU 原点必须由现场标定统一；两机时间同步必须在后端完成。前端拒绝非数值坐标、负标准差、未知枚举和置信度越界；实时观测时间偏差超过 5 秒将被拒收，部署时需同步浏览器终端和后端时钟。

### 云台视频

默认 ID `ptz01`，可在接入配置中修改。当前 Python 后端只提供两路固定相机，云台并不会自动出现。后续需在网关增加云台通道并在 `cameraIds` 中声明，提供同样的 MJPEG 接口。前端“聚焦”只改变空域视角，不发送转动、变焦或自动指向指令。

## 现场部署边界

- 线上版本仅作私有演示，不能自动访问学校内网。校园实时版本应置于经过认证的同源网关之后，统一代理网页、`/api`、`/ws` 和视频；WebSocket 需支持 Upgrade，视频代理需关闭缓冲。
- 不要把 RTSP 用户名/密码写入网页、查询参数或代码。前端不保存密码；认证应由内网网关或学校 SSO 完成。原有后端启用 Basic Auth 时，须通过同源登录上下文验证 HTTP 和 WebSocket，不能只保护网页首页。
- 跨域地址需学校自行配置 HTTPS、受限 CORS 与认证。当前 fetch 使用 `credentials: same-origin`，不支持跨域会话凭据自动转发。HTTPS 演示页会拒绝 HTTP 网关地址。
- 不要将 `npm run dev` 或 `wrangler dev` 作为长期公共生产服务。正式上线还需要内网部署方案、账号权限、访问审计、保留策略和安全复核。
- 校园几何与演示机位都是示意，真实模式仅使用坐标网格，需后续引入经过测绘配准的校园模型。图层误差范围是对角标准差的投影示意，不是完整协方差置信椭球。
- **1 km 是界面显示范围，不是检测或分类能力承诺。** 真实识别能力、定位精度、延时和误报率必须现场验收。
- “已确认”指轨迹状态，不代表违法或危险。只有确认且非鸟类的新增事件才可触发本机提示；授权状态仍为未核验。已阅标记不写回后端，刷新后清除。

## 验证

```powershell
npm test
npm run typecheck
npm run lint
npm run build
```

单元测试覆盖四类模拟数据的接口兼容、异常消息、乱序保护、历史容量、速度与轨迹一致性、三维投影、网关地址约束、录像路径和健康数据校验。没有连接真实摄像头做现场验收，也不声称已完成浏览器人工测试。

Lint 针对业务源码，不扫描脚手架提供的 `components/ui` 与 `hooks`。本项目未启用 React Compiler，因此关闭其专用优化规则，保留 Hook 正确性检查。交互式 SVG 使用 ARIA 角色并提供键盘等价操作；MJPEG 不使用静态图片优化器。

## 文件结构

- `components/monitoring-workspace.tsx`：工作台、视频、事件和配置交互。
- `components/airspace-view.tsx`：投影视图、图层、视角控制。
- `lib/airspace.ts`：数据契约、校验、投影和模拟轨迹。
- `lib/use-airspace.ts`：模拟时钟、网关连接、重连和轨迹过期。
- `app/globals.css`：统一主题及响应式样式。
- `tests/airspace.test.mjs`：数据与几何单元测试。

分享封面 `public/og.png` 由内置图像工具生成，提示为：海雾蓝与暖白极简航空监测品牌卡，左侧精确标题“云瞳 AIRSPACE”、文案“校园低空安全监测平台”与“3D AIRSPACE · LIVE MONITORING”，右侧为抽象等距校园及蓝绿飞行轨迹，无额外文字。页面三维视图不是图片，而是数据驱动的交互投影。
